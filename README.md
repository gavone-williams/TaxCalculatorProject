# Tax Calculator Project

**Course:** CSC320 — Java Programming  
**Assignment:** Module 3 Critical Thinking — Option #1: Calculate Average Withholding  

## Description
This Java application prompts the user for their gross weekly income and calculates their weekly tax withholding and net take-home pay based on predefined income tax brackets.

## Tax Brackets
- **Income < $500:** 10% tax rate
- **$500 ≤ Income < $1500:** 15% tax rate
- **$1500 ≤ Income < $2500:** 20% tax rate
- **Income ≥ $2500:** 30% tax rate

## How to Run
1. Compile: `javac TaxCalculator.java`
2. Execute: `java TaxCalculator`
